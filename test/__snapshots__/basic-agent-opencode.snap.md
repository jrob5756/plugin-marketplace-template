## Install

Copy or symlink the `.opencode/` directory into your project root:

```bash
# from this directory
cp -R .opencode /path/to/your/project/
```

Or install globally:

```bash
mkdir -p ~/.config/opencode
cp -R .opencode/* ~/.config/opencode/
```
